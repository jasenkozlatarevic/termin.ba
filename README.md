# termin.ba

A web platform for booking football and sports venues in Sarajevo and finding players to join games.

## Project Description

Termin.ba is designed to make organizing recreational football and sports activities easier.

Users can:
- Discover football and sports venues in Sarajevo
- View venue details and available information
- Reserve available time slots
- Create games
- Join existing games
- Manage their profile
- View their games and reservations

## Main Features

- User registration and login
- Sports venue discovery
- Venue details
- Time slot reservation
- Game creation
- Joining existing games
- User profile
- Responsive web interface
